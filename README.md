# DilDostu — Context-Aware Language Learning App (Azerbaijani → English)

A mobile app that helps Azerbaijani speakers learn English. It uses the user's location and the time of day (café, airport, office…) to generate vocabulary and example sentences for that exact situation, live with AI.

## Key features
- **Context-aware learning** — vocabulary chosen from GPS location and time
- **Live AI backend** — personalised words and examples generated by an LLM
- **Offline fallback** — switches to built-in content packs when the server is unreachable
- **Level-adaptive content**

## Structure
| Folder | What it is |
|---|---|
| `app/` | Flutter mobile app (Android) |
| `server/` | FastAPI backend — prompt building and LLM provider fallback (Groq / Claude) |
| `content_gen/` | Scripts that generate the static content packs |

## Tech stack
Flutter / Dart · Python · FastAPI · Groq · Claude API
